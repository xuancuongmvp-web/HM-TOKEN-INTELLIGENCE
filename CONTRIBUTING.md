# Contributing

Thank you for helping improve HM Token Intelligence.

Report reproducible issues with a minimal safe input, selected tokenizer, expected and actual results, and Python/tiktoken versions. Never publish API keys, credentials, customer data, or confidential prompts.

Pull requests should add tests, preserve fail-closed behavior for unknown tokenizers, avoid claiming complete hosted-chat usage from text-only counts, and keep lossy semantic compression opt-in and reviewable.
